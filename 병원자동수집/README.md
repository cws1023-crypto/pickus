# 강남역 반경 3km 병·의원 자동수집

## 준비 (최초 1회)
1. Python 설치: https://www.python.org/downloads/ (설치 시 "Add python.exe to PATH" 체크)
2. 공공데이터포털 인증키 발급(무료)
   - https://www.data.go.kr 에서 "건강보험심사평가원_병원정보서비스" 검색 → 활용신청 (보통 즉시 승인)
   - 마이페이지 → 일반 인증키(**Decoding**) 복사
3. 이 폴더 파일(`collect_hospitals.py`, `실행.bat`)을
   `C:\Users\user\OneDrive\Desktop\오파독 작업\병원자동수집` 에 복사

## 실행
`실행.bat` 더블클릭 → 인증키 붙여넣기 → 완료되면 같은 폴더에
`강남역_3km_병의원_YYYYMMDD.xlsx` 가 생성됩니다.

옵션: `python collect_hospitals.py --key 키 --radius 2000` (반경 변경), `--no-email` (이메일 수집 생략)

## 엑셀 컬럼
수집일자 · 수집경로 · 수집경로세부 · 이름 · 회사명(병원명) · 직책 · 휴대폰 · 회사전화 · 팩스 · 이메일 · 주소 · 홈페이지 · 업종(종별)
+ 강남역거리(m) · 의사수 · 개설일자 · 이메일수집메모

- 이름/직책/휴대폰/팩스: 공공데이터에 없어 빈칸
- 이메일: 병원 홈페이지에 공개된 주소만 수집. 홈페이지에 "이메일 무단수집 거부"가 게시된 곳은 수집하지 않음
