# 03 매일 스레드 자동화

중소기업 대표와 사업가를 위한 Threads 게시물 자동화의 기획·설계 자료입니다.

**현재 단계: 설계 및 검토용 Google Sheets 준비 완료. 실행 프로그램, Make 시나리오, 계정 연결 및 실제 게시 자동화는 아직 구현·활성화하지 않았습니다.**

한국 시간(Asia/Seoul)으로 매일 오전 04:00에 초안 1개를 작성하고, 사용자가 검토·승인한 글만 오전 07:00 이후 게시하는 구조를 설계했습니다.

## 자료

- [전체 설계도](docs/전체설계도.md): 연결 구조, 자료 조사, 승인, 게시, 예외 처리
- [Make 구현 명세](docs/Make-구현명세.md): 초안 작성·승인 게시 시나리오 설정
- [주제 편성](docs/주제-편성.md): 9개 분야 순환 제안과 30개 후보의 관계
- [시트 구조와 승인](docs/시트-구조와-승인.md): 실제 탭·헤더와 추가 예정 필드
- [운영 및 검증](docs/운영-및-검증.md): 연결·테스트·활성화 순서
- [게시물 작성 지시문](prompts/게시물-작성.md): 친근한 반말, 출처 확인, 반복 방지
- [후보 주제 CSV](data/topics.csv) / [JSON](data/topics.json): 후보 30개
- [분야 순환 제안](data/category-rotation.json): 9개 분야 순서
- [검토함 샘플](data/review-sample.csv): 게시 예정일이 비어 있는 샘플 1개
- [시트 내용 스냅샷](snapshots/sheets.json): 5개 탭의 내용 보관

## 현재 상태

| 항목 | 상태 |
| --- | --- |
| 후보 주제 | 30개, 모두 검토대기·사용안함 |
| 검토함 | 구조 확인용 샘플 1개 |
| 글쓰기 말투 | 친근한 반말, 짧은 문장과 문단 |
| 일정 | 04:00 초안 / 07:00~23:55 승인 확인을 설계 |
| 분야 순환 | 9개 분야 순환 제안, 기존 주제에 분야 ID는 아직 없음 |
| 계정 연결·실제 테스트 게시 | 미완료 |
| 본문 수정 시 자동 승인 해제 | 미구현; 승인 취소 → 수정 → 재승인으로 운영 |

## 설계의 우선순위

후보 주제의 단순 1→30 순환을 먼저 설계한 뒤, 9개 분야별 순환을 추가로 제안했습니다. 최신 방향은 [전체 설계도](docs/전체설계도.md)이며, 분야 매핑과 추가 필드는 구현 전에 보완해야 합니다. 초기 Make 명세와 원본 스냅샷은 그대로 보관합니다.

## 보관과 동기화

원본은 Google Drive의 `오파독 작업 / 03 매일 스레드 자동화` 폴더에 있는 운영 시트입니다. 저장소의 스냅샷은 **2026-11-15(한국 시간)에 읽은 내용**이며 이후 시트 변경을 자동 동기화하지 않습니다.

CSV는 UTF-8 BOM과 CSV 이스케이프를 적용했습니다. 샘플의 빈 게시 예정일과 모든 주제의 비활성 상태를 유지했습니다. 계정 키나 로그인 정보는 포함하지 않습니다.
