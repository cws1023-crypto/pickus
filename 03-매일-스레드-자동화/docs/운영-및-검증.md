# 운영 및 검증

## 구축 순서

1. 주제 확정과 분야 매핑
2. 시트의 추가 필드 보완
3. Buffer에 Threads 계정 연결
4. Make에 Google Sheets·OpenAI API·Buffer 연결
5. 초안 시나리오 구성: 매일 04:00, Asia/Seoul
6. 승인 게시 시나리오 구성: 07:00~23:55, 5분 간격 제안
7. 조건 검증과 사용자 승인 테스트 글 1개 실제 게시 확인
8. 예약 실행 활성화

Make 요금제의 최소 실행 간격을 확인합니다. OpenAI API 글 작성·웹 검색 비용은 ChatGPT 구독과 별도입니다.

## 자료 확인

Make HTTP 모듈에서 OpenAI Responses API의 웹 검색 기능을 호출하는 설계입니다. 실제 검색 호출 여부와 원문 출처를 확인하고 작성 호출에는 확인한 근거만 전달합니다.

- 지원사업: 기업마당, 소상공인시장진흥공단, 중소벤처기업부, 복지로
- 세무: 국세청
- 법령: 국가법령정보센터
- 노무: 고용노동부

지원 대상·지역·기간·금액·예외를 확인하며 근거가 부족하면 사실확인필요로 보관합니다.

## 활성화 전 검증

- [ ] 미채택·사용안함 주제를 임의로 선택하지 않는다.
- [ ] 미승인·보류·사실확인필요 글은 게시하지 않는다.
- [ ] 7시 전 승인 글은 7시 이전에 게시하지 않는다.
- [ ] 7시 이후 승인 글은 다음 확인 실행에서 처리한다.
- [ ] 전날 미승인 글을 다음 날 자동으로 게시하지 않는다.
- [ ] 같은 계정의 당일 초안을 중복 생성하지 않는다.
- [ ] 순환 상태는 초안 저장 성공 후에만 갱신한다.
- [ ] 게시 동시성을 1로 제한하고 하루 1개만 처리한다.
- [ ] 처리중·전달완료·결과확인필요가 있으면 다른 글을 보내지 않는다.
- [ ] Buffer 접수 ID를 기록하고 승인한 본문 그대로 보낸다.
- [ ] 접수 결과가 불명확하면 자동 재전송하지 않는다.
- [ ] Buffer 접수와 실제 Threads 게시 성공을 구분한다.
- [ ] 시트 기록 실패 시 Buffer 이력을 대조해 중복을 막는다.
- [ ] 실제 플랫폼의 글 길이 제한을 검증한다.

위 항목은 구현 후 수행할 점검이며 이번 문서 업로드에서 실행 완료한 테스트가 아닙니다.
