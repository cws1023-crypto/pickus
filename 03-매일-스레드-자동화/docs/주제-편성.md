# 주제 편성

## 분야 순환 제안

첨부한 주제 순위에 따라 하루 한 분야씩 1→9→1로 순환하는 제안입니다. 첨부 자료는 릴스 조회수 참고 자료이며 Threads에서도 같은 성과가 난다는 의미는 아닙니다. 원본 이미지의 출처·수집 기간·표본을 검증하지 않았으므로 조회수 숫자는 성과 근거로 재사용하지 않습니다.

| 순서 | 분야 | 예시·다룰 내용 |
| --- | --- | --- |
| 1 | 지원금 · 생활·복지 | 예시: 사장이라고 생활·복지 지원 대상에서 무조건 빠질까? 사업가·가구의 실제 대상 조건과 지역·신청 시기 확인. |
| 2 | 자영업 운영·마케팅 | 예시: 매출은 늘었는데 통장엔 돈이 없지? / 견적서는 빨리 보내는데 계약은 왜 안 될까? |
| 3 | 세금·절세 | 예시: 절세하는 사업가? 탈세하는 사업가? / 법인카드로 긁었으니 다 비용 아닌가? |
| 4 | 기타 · AI·업무 개선 | 예시: 중소기업 AI 활용, 우리 회사는 어디쯤일까? / AI 구독료만 늘고 야근은 그대로라면? |
| 5 | 지원금 · 사업자·소상공인 | 예시: 정부지원금, 공짜 돈인 줄 알았어? 자부담·지원 대상·정산 의무·중복 수혜 조건 확인. |
| 6 | 노무·고용 | 예시: 좋은 사장이라면 근로계약서는 대충 써도 될까? / 사람이 부족한 걸까 일이 꼬인 걸까? |
| 7 | 정책자금 | 예시: 정책자금, 금리만 낮으면 좋은 선택일까? 보증료·상환·자격·접수 상태 확인. |
| 8 | 창업·사업자 세팅 | 예시: 법인으로 바꾸면 세금이 무조건 줄까? / 동업 지분 50 대 50, 공평한데 왜 불안하지? |
| 9 | 법인·대표 재무 | 예시: 법인 정관, 설립할 때 받은 파일 그대로야? / 대표 월급 vs 배당, 뭐가 더 남을까? |

## 후보와 연결하는 방법

1. 후보를 검토해 ‘채택’과 ‘사용’을 선택합니다.
2. 분야 ID와 안정적인 주제 ID를 추가하고 후보를 분야에 매핑합니다. 이 매핑은 아직 실행하지 않았습니다.
3. 마지막 초안 저장 성공 분야 다음 분야에서 사용 중인 세부 주제를 고릅니다.
4. 준비된 주제가 없는 분야는 건너뛰고 미채택 주제는 임의로 활성화하지 않습니다.
5. 같은 주제가 돌아오면 대상·업종·실수·준비 서류·점검 질문을 바꿉니다. 최근 30개 글과 같은 주제 이력을 비교합니다.

후보에는 AI·세금·법인·경영 관련 내용이 많이 포함되어 있습니다. 생활·복지 지원금 등 일부 분야에는 후보를 추가해야 합니다.
